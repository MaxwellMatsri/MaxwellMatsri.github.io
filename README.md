# Maxwell Kofi Matsri's portfolio

A responsive, static portfolio based on [Gitfolio](https://github.com/gunadizz/gitfolio) by Gunadi Renta. It uses no build step or external runtime dependencies.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static HTTP server. The portrait uses a relative URL, so the site also works under a GitHub Pages repository subpath.

## Publish with GitHub Pages

1. Create a repository in a GitHub account or organization where you have permission to publish. Do not push this branch to the upstream Gitfolio repository.
2. Push the portfolio files to that repository's default branch, including `index.html` and `assets/maxwell-matsri.jpg`.
3. In the new repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and **/ (root)**, and save.
4. Wait for the Pages deployment to finish and open the URL shown in Settings. A project site usually appears at `https://<username>.github.io/<repository>/`; an account site named `<username>.github.io` appears at the domain root.

GitHub Pages availability and visibility depend on the repository and account settings.

## Personalization and privacy

Edit `index.html` to update experience, skills, projects, or contact links. The email address and phone number are displayed publicly as requested; the original CV and references are not included. Review the content, contact information, and portrait before making the repository public.

Select **Book an appointment** in the contact section to open the form. Requests are submitted directly to [FormSubmit](https://formsubmit.co/), which shows any verification step and its confirmation or error page. The first submission triggers an activation email; confirm it before requests can be delivered to the contact email. FormSubmit says it retains submissions for up to 30 days. The form requests an appointment rather than booking one automatically.

If requests are not arriving, check the contact email's inbox and spam folder for FormSubmit's activation message and confirm it. If FormSubmit reports an error, note its message and use the direct email link to follow up; a network failure may occur after a request was received, so resending can create duplicates.

Only the personalized entry point and portrait are needed for deployment; the original template's sample pages are not part of this portfolio.
